# Stylumia Trend Signal Eval

A dependency-free Node.js utility for the Stylumia AI Engineering Intern application. It evaluates whether a fashion, beauty, or home trend has enough cross-channel evidence to use in a demand-sensing workflow.

The checker validates observation windows and channels, requires at least two evidence sources, and assigns a high, medium, low, or reject confidence label from the average demand movement.

## Run

```bash
npm test
```
